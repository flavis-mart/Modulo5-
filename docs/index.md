# Lista de Exercícios do módulo 5 - Trilha de documentação

### Exercício 1
Como instalar o aplicativo de organização Notion em desktops: Entre no link disponível: [Notion] (https://www.notion.com/pt/desktop), selecione o seu sistema operacional e clique no botão em destaque ***Baixar***. Quando o download estiver completo, abra o arquivo e siga as instruções do sistema para configuração inicial. O programa abrirá sozinho quando este processo acabar e você recebrá um tutorial para começar a explorar o sistema por conta própria.
